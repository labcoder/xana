# Focused image services

Focused services are named, profile-exposed operations independent from Xana's
conversational model. The current production adapter is `openai.images` for
direct OpenAI API-key image generation. ChatGPT/Codex subscriptions are not
used for this path.

```toml
[service_connections.openai-images]
adapter = "openai.images"
credential = { source = "environment", variable = "OPENAI_API_KEY" }

[service_routes.illustrate]
operation = "image.generate"
connection = "openai-images"
model = "gpt-image-2"
description = "Default quality illustration route"
default = true
options = { quality = "high", size = "1024x1024", output_format = "png" }
egress_policy = "image-prompts"

[egress_policies.image-prompts]
allowed = ["prompt_text", "selected_artifacts"]
```

Add `"illustrate"` to the selected profile's `service_routes`. A route being
configured or exposed does not authorize a paid request: invocation still
uses Xana's ordinary permission and outbound-data gates. Missing credentials,
unexposed routes, incompatible operations, unsupported options, or absent
defaults fail before network use. Xana never silently switches route, provider,
model, quality, or price tier.

The OpenAI adapter supports text-to-image with `gpt-image-2` and pinned
snapshots. Options are `size`, `quality`, `output_format`, `background`,
`moderation`, and `output_compression`; output count is fixed at one. Editing
is not currently exposed. Generated bytes are signature-checked, bounded, and
published as immutable Xana artifacts. Results retain route, connection,
adapter, model, safe options, timestamp, token usage when returned, and whether
cost information was available. Provider error bodies, prompts, authorization
headers, and base64 bytes are not persisted in activity or session records.

Authentication, rate limit, quota, content-policy, timeout, cancellation,
oversized response, malformed response, and artifact publication are distinct
failures. A synchronous provider request cannot prove remote cancellation after
dispatch, and Xana never retries an ambiguous paid generation.
