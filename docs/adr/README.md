# Architecture decisions

> Audience: Contributors and coding agents
> Authority: Historical rationale

Xana uses sparse Architecture Decision Records. Add one only when a choice is
costly to reverse, surprising without context, and emerged from a genuine
tradeoff. Architecture describes the implemented contract; an ADR explains
why a consequential contract was chosen.
