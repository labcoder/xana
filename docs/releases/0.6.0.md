# Xana 0.6.0 — Interoperable

Xana 0.6.0 expands the local personal-agent harness into a bounded integration
host while preserving Xana's existing native and managed conversation paths.

This release adds:

- optional projects, reusable profiles, and portable project configuration;
- Agent Skills discovery and scoped Agent Plugin installation and lifecycle;
- bounded MCP stdio and Streamable HTTP clients, OAuth support, and a local
  stdio Xana MCP server;
- trusted A2A agent discovery, delegation, streamed status, cancellation, and
  artifact ingestion;
- explicit outbound-data review, saved exact decisions, redacted audit records,
  and zero-send denial guarantees;
- typed image-generation routes through OpenAI and OpenRouter without silent
  provider fallback;
- multiple-image conversational input, specialist vision fallback, clipboard
  acquisition, and external-image approval; and
- guided integration setup, recovery-aware Doctor checks, bounded structured
  logs, crash diagnostics, and support-bundle export.

The terminal experience also gains the unified interactive setup flow, live
theme previews, improved management forms, activity inspection, and Xana's
animated startup portrait. Optional integrations remain inert until explicitly
configured and exposed by a selected profile.

## Preview trust limits

These binaries remain unsigned developer previews. The macOS archives are not
signed with Apple Developer ID and are not notarized. The Windows executable is
not Authenticode-signed. SHA-256 verifies bytes against the release manifest,
and GitHub attestations bind assets to the repository workflow and commit, but
neither is an operating-system publisher signature. Do not weaken Gatekeeper,
SmartScreen, execution policy, antivirus, or other host security controls.

Package-manager channels, automatic updates, retained installer rollback,
native signing/notarization, desktop binaries, and a support SLA remain outside
this preview.
