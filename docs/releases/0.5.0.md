# Xana 0.5.0 Developer Preview

Xana 0.5.0 is the first installable developer preview of the local personal AI
agent and harness. It combines provider-neutral native conversations, managed
Codex subscription sessions, durable history, explicit permissions, bounded
tools and artifacts, supervised child-agent orchestration, plain/one-shot
automation, an adaptive terminal UI, multi-conversation local hosting, and
transactional setup and recovery.

The preview adds verified per-user installers for Windows x64, Apple Silicon
macOS, Intel macOS, and x64 glibc Linux. Re-running an installer performs an
explicit latest or exact-version reinstall, upgrade, or downgrade; it never
acts as a background updater. Installation and Xana configuration remain
separate, and existing valid setup is preserved.

## Preview trust limits

These binaries are unsigned developer previews. The macOS archives are not
signed with Apple Developer ID and are not notarized. The Windows executable is
not Authenticode-signed. SHA-256 verifies bytes against the release manifest,
and GitHub attestations bind assets to the repository workflow and commit, but
neither is an operating-system publisher signature. Xana does not recommend
weakening Gatekeeper, SmartScreen, execution policy, antivirus, or other host
security controls.

Package-manager channels, automatic updates, retained installer rollback,
native signing/notarization, desktop binaries, and a support SLA are not part
of this preview.
