# Xana 0.7.0 — Interfaces

Xana 0.7.0 completes the Interfaces milestone. Xana's Rust-owned runtime now
supports semantically consistent plain, TUI, and native GPUI Desktop clients
without moving credentials, permission policy, or execution authority into a
frontend.

This release:

- adds a native GPUI Desktop preview in the same Cargo workspace, with
  attach-or-own host lifecycle, single-instance forwarding, recovery-first
  startup, and no CLI/TUI graphical dependency leakage;
- supports multiple workspaces and concurrent Conversations with explicit
  controller/observer ownership, branching, attention, recovery, and Espejo
  supervision;
- projects bounded snapshots, ordered deltas, completion receipts, execution
  facts, prompt budgets, usage observations, approvals, activity, attachments,
  artifacts, and safe rich-content fallbacks across clients;
- adds shared command-driven setup, settings, connection, model, Project,
  Profile, integration, permission, doctor, repair, and reset workflows;
- improves native agent readiness with model-aware context budgeting, durable
  derived compaction, typed file/search/write tools, outbound-gated HTTPS fetch,
  and resumable round-budget suspension; and
- hardens long conversations and rich resources with bounded projections,
  streamed ingestion, decoded-image limits, deferred UI updates, frame
  diagnostics, fault recovery, and cross-platform CI.

Desktop is intentionally a preview surface in 0.7.0. Final visual polish, real
assistive-technology evidence, clean 60/120+ Hz reference measurements, and a
local web client remain future Interface Maturity work. Their absence is not a
claim that those quality gates passed.

## Preview trust limits

These binaries remain an unsigned developer preview. The macOS archives are
not signed with Apple Developer ID and are not notarized. Windows executables
are not Authenticode-signed. SHA-256 verifies bytes against the release manifest,
and GitHub attestations bind assets to the repository workflow and commit, but
neither is an operating-system publisher signature. Do not weaken Gatekeeper,
SmartScreen, execution policy, antivirus, or other host security controls.

Package-manager channels, first-class updates and rollback, native signing and
notarization, and a support SLA remain Product Distribution work. The release
does not expose Xana to a LAN or public network and does not ship local web.
