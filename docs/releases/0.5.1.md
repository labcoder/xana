# Xana 0.5.1 Developer Preview

Xana 0.5.1 is a corrective release candidate for the first installable Xana
developer preview. It retains the 0.5.0 application feature set while repairing
and simplifying the no-publish release path discovered during remote preview
verification.

This patch:

- checks out the exact repository source before invoking the draft helper;
- requires a successful three-platform `main` CI run for the exact release
  commit instead of repeating the same quality matrix after a tag;
- keeps all four native release archives as fresh platform builds rather than
  reusing CI binaries or mutable prebuilt artifacts;
- adds a commit-pinned dependency-only Rust cache to ordinary CI and prevents
  tag pushes from starting a duplicate CI run; and
- strengthens portable checksum, archive, fixture-cleanup, workflow, and CI
  evidence checks used by the release pipeline.

## Preview trust limits

These binaries are unsigned developer previews. The macOS archives are not
signed with Apple Developer ID and are not notarized. The Windows executable is
not Authenticode-signed. SHA-256 verifies bytes against the release manifest,
and GitHub attestations bind assets to the repository workflow and commit, but
neither is an operating-system publisher signature. Xana does not recommend
weakening Gatekeeper, SmartScreen, execution policy, antivirus, or other host
security controls.

Package-manager channels, automatic updates, retained installer rollback,
native signing/notarization, desktop binaries, and a support SLA remain outside
this preview.
