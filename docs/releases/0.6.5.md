# Xana 0.6.5 — Hardening

Xana 0.6.5 hardens the Interoperable milestone while reducing duplicated and
unused implementation surface. Existing provider, orchestration, TUI, and
security boundaries remain intact.

This release:

- completes the configured MCP OAuth lifecycle with explicit login and logout,
  PKCE loopback authorization, operating-system token storage, expiry-aware
  refresh, and recipient identity binding;
- includes MCP OAuth credential references in recovery and reset inspection;
- consolidates MCP catalog pagination behind one bounded cursor guard;
- centralizes native-provider composition, configuration edit transactions,
  shared chat contracts, and focused-service result provenance;
- removes unused document extraction, MCP readiness, catalog accessor, and
  compatibility surfaces plus their tautological coverage; and
- retains focused security and integration coverage for provider transport,
  credential recovery, MCP discovery, authorization, and cancellation.

## Preview trust limits

These binaries remain an unsigned developer preview and are not a public
release. The macOS archives are not signed with Apple Developer ID and are not
notarized. The Windows executable is not Authenticode-signed. SHA-256 verifies
bytes against the release manifest, and GitHub attestations bind assets to the
repository workflow and commit, but neither is an operating-system publisher
signature. Do not weaken Gatekeeper, SmartScreen, execution policy, antivirus,
or other host security controls.

Package-manager channels, automatic updates, retained installer rollback,
native signing/notarization, desktop binaries, and a support SLA remain outside
this preview.
