# Phase 3 original implemented subset

> Audience: Contributors and coding agents  
> Authority: Historical
> Status: Superseded by proposal 0015

This record captured the first structural Phase 3 slice delivered with Xana
0.2.0: the Cargo workspace, capability resolver, bounded self-documentation,
text/CSV document extraction, provider adapter prototypes, credential
lifecycle test primitives, and artifact-backed image references.

It deliberately did not claim production authenticated providers, managed
Codex subscription access, model catalogs/selection, or complete wire-edge
image support. Those gaps were revisited rather than preserved. The complete
implemented Chapter 3 result is now recorded by
[proposal 0015](0015-connections-models-and-managed-runtimes.md) and the
descriptive Architecture documents.
